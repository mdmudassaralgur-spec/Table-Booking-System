# Table-Booking-System
TableBook - Restaurant Table Reservation & Management PlatformTableBook is a modern, single-page web application designed to simplify restaurant table reservations, seating floor plans, and guest management. Built as a full-featured frontend solution, it provides real-time table availability tracking, dynamic CRUD operations for bookings and tables, interactive floor visualization, customer profile tracking, and performance reporting.🛠️ Step-by-Step Project Implementation & Setup Guide
Step 1: Set Up the Project StructureCreate a clean directory on your computer for the project and add the necessary application files:mkdir tablebook-app
cd tablebook-app
Inside this folder, create two primary files:index.html (contains all structure, Tailwind styling, and JavaScript logic)README.md (project documentation)
Step 2: Initialize HTML5 & DependenciesIn index.html, set up standard HTML5 boilerplate along with the required CDN references:Tailwind CSS: https://cdn.tailwindcss.com for utility classes and purple color scheme configuration (#8B5CF6).Font Awesome 6: https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.4.0/css/all.min.css for icons.Google Fonts: Inter font family for modern typography.
Step 3: Construct the Core Layout & ModulesBuild the user interface using a responsive flexbox/grid layout:Sidebar Navigation: Add links for all core views (#dashboard, #tables, #bookings, #layout, #customers, #availability, #calendar, #reports).Header Bar: Include mobile drawer buttons, user role switcher (Admin, Manager, Staff), and Dark Mode toggle.Module Views: Create hidden container sections (<section id="...">) for each page module so JavaScript can switch active screens smoothly.
Step 4: Define JavaScript Data Models & State PersistenceSet up in-memory arrays to manage core application data without a backend database:tables: Array storing table ID, capacity, floor, zone location, and status (Available, Reserved, Occupied, Out of Service).bookings: Array storing reservation details, assigned table IDs, party size, date/time, and status.customers: Array tracking customer visit history and dietary preferences.Connect data state to localStorage:function saveData() {
    localStorage.setItem('tb_tables', JSON.stringify(tables));
    localStorage.setItem('tb_bookings', JSON.stringify(bookings));
    localStorage.setItem('tb_customers', JSON.stringify(customers));
    refreshCurrentView();
}
Step 5: Implement Core Interactive ModulesDashboard: Calculate live metrics (occupancy rates, estimated revenues, active tables) dynamically from current state data.CRUD Modals: Build interactive forms for creating/editing tables and reservations with dynamic dropdown population.Visual Floor Plan: Dynamically render table cards by selected floor level (Ground / First) with color-coded status rings.Real-time Availability Checker: Query non-conflicting tables matching guest counts and time slots.Analytics & CSV Exporter: Generate live data distribution bars and handle .csv downloadable exports using standard Data URIs.
Step 6: Run & Test the ApplicationOpen index.html directly in any web browser (Chrome, Firefox, Safari, Edge).Test adding a new table in Table Management.Create a reservation in Booking Management and verify the dashboard metrics update automatically.Toggle to Visual Layout to observe real-time status updates.Test dark mode and switch roles from the top navigation bar.
